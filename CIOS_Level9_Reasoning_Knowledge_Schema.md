# CIOS LEVEL 9 --- REASONING KNOWLEDGE SCHEMA v2

## Creative Intelligence Operating System

## Purpose

This document defines the standard structure for converting raw
knowledge into expert-level decision intelligence.

The objective is not to store information.

The objective is to create knowledge blocks that allow an LLM to reason
like:

-   Creative Director
-   Art Director
-   Designer
-   Photographer
-   Marketing Strategist

The transformation:

    Knowledge = Information

into:

    Knowledge = Contextual Decision Intelligence

------------------------------------------------------------------------

# 1. Core Principle

Traditional knowledge:

    Negative space creates premium feeling.

is insufficient.

A professional decision requires:

    When:
    Luxury skincare campaign

    Audience:
    Women 35-50

    Objective:
    Premium positioning

    Decision:
    Use controlled negative space

    Reason:
    Creates confidence, refinement and perceived value

    Avoid:
    Crowded composition

    Trade-off:
    Lower information density but stronger premium perception

Every knowledge block must answer:

1.  What is the rule?
2.  When does it apply?
3.  Why does it matter?
4.  When should it not be used?
5.  What alternative exists?
6.  What business or creative impact does it create?

------------------------------------------------------------------------

# 2. Knowledge Block Architecture

Every knowledge unit must follow this structure:

``` yaml
id:

name:

domain:

category:

knowledge_type:

authority_level:

creative_stage:

context:

decision:

reason:

use_when:

avoid_when:

trade_off:

examples:

anti_patterns:

related_blocks:

confidence:

source:
```

------------------------------------------------------------------------

# 3. Field Definitions

## id

Unique identifier.

Example:

    layout.luxury_negative_space.hero

------------------------------------------------------------------------

## name

Human-readable knowledge title.

Example:

    Luxury Negative Space Hero Composition

------------------------------------------------------------------------

## domain

Main CIOS domain.

Examples:

    layout
    typography
    photography
    category
    audience
    strategy

------------------------------------------------------------------------

## category

Industry or context.

Examples:

    beauty
    fashion
    food
    technology
    automotive

------------------------------------------------------------------------

## knowledge_type

Defines the role of knowledge.

Allowed types:

    principle

    decision_rule

    framework

    pattern

    anti_pattern

    example

    evaluation_rule

    production_rule

------------------------------------------------------------------------

## authority_level

Knowledge confidence.

Example:

    core

    expert

    specialized

    experimental

------------------------------------------------------------------------

## creative_stage

Where this knowledge is applied.

Examples:

    strategy

    concept

    visual_direction

    layout

    production

    evaluation

------------------------------------------------------------------------

# 4. Decision Knowledge Format

The most important component.

Structure:

``` yaml
decision:

situation:

choose:

avoid:

reason:

expected_effect:
```

Example:

``` yaml
decision:

situation:
Premium skincare launch targeting mature women

choose:
- editorial composition
- soft diffused lighting
- controlled highlights

avoid:
- aggressive commercial style
- excessive decoration

reason:
Premium perception depends on trust, refinement and confidence

expected_effect:
Higher perceived brand value
```

------------------------------------------------------------------------

# 5. Context Matching System

Knowledge must not activate universally.

It requires conditions.

Example:

Wrong:

    Use dark backgrounds for luxury.

Correct:

``` yaml
context:

brand:
luxury

industry:
fashion

objective:
brand awareness

audience:
premium consumers
```

Then:

    Use dark tones when they support exclusivity.

# 7. Anti-Pattern Knowledge

Level 9 systems must know what NOT to do.

Schema:

``` yaml
anti_pattern:

name:

problem:

why_it_fails:

replacement:
```

Example:

``` yaml
anti_pattern:

name:
Generic skincare beauty shot

problem:
Looks identical to competitors

why_it_fails:
No differentiation or emotional meaning

replacement:
Identity-based storytelling
```

------------------------------------------------------------------------

# 8. Trade-off Knowledge

Experts understand compromises.

Schema:

``` yaml
trade_off:

benefit:

cost:

recommended_when:
```

Example:

``` yaml
trade_off:

choice:
Minimal luxury layout

benefit:
Premium perception

cost:
Less information density

recommended_when:
Brand awareness campaign
```

------------------------------------------------------------------------

# 9. Example Knowledge Format

Examples are not references only.

They are extracted intelligence.

Schema:

``` yaml
example:

reference:

context:

why_successful:

creative_decision:

visual_decision:

transferable_rule:
```

Example:

    Reference:
    Apple product campaign

    Why successful:
    Simple concept with strong emotional association

    Transferable rule:
    Technology brands should communicate human benefit, not only technical specifications.

------------------------------------------------------------------------

The LLM should process:

    Brief

    ↓

    Context extraction

    ↓

    Retrieve decision knowledge

    ↓

    Compare possible directions

    ↓

    Select best decision

    ↓

    Explain reasoning internally

    ↓

    Generate creative output

------------------------------------------------------------------------

# 14. Knowledge Quality Checklist

Before adding any knowledge block:

Check:

## Context

Does it explain when it applies?

## Decision

Does it recommend an action?

## Reason

Does it explain why?

## Limitation

Does it explain when not to use?

## Example

Can another expert understand it?

## Transferability

Can it apply to new situations?

------------------------------------------------------------------------

# 15. Bad Knowledge vs Good Knowledge

## Bad:

    Use cinematic lighting.

## Good:

    Situation:
    Luxury automotive campaign

    Decision:
    Use controlled directional lighting with deep contrast

    Reason:
    Creates authority and premium perception

    Avoid:
    Flat commercial lighting

    Trade-off:
    Less approachable but stronger prestige signal

The Reasoning Knowledge Layer is the intelligence foundation of CIOS
Level 9.

Raw information

into:

Expert decisions.
